Preview

Command

:2,$-1j<cr>:2s/,\s*}/ }/g<cr>:2s/,\s*$//<cr>
  1. :2,$-1j 2행부터 마지막 직전 행까지의 모든 객체 라인을 한 줄로 결합
  2. <cr> 명령 실행
  3. :2s/,\s*}/ }/g 각 객체 내부 프로퍼티 뒤의 후행 쉼표 제거
  4. <cr> 치환 명령 실행
  5. :2s/,\s*$// 배열 마지막 원소 뒤에 붙은 후행 쉼표 제거
  6. <cr> 치환 명령 실행
