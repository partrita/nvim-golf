# Increment Numbers

<!-- difficulty: beginner -->

여러 숫자를 한 번에 1씩 증가시킵니다.

## Before

```text
0
0
0
```

## After

```text
1
1
1
```

## Command

```
<ctrl-a>j<ctrl-a>j<ctrl-a>
```

1. `<ctrl-a>` 첫 번째 줄 숫자 1 증가
1. `j` 다음 줄로 이동
1. `<ctrl-a>` 두 번째 줄 숫자 1 증가
1. `j` 다음 줄로 이동
1. `<ctrl-a>` 세 번째 줄 숫자 1 증가
